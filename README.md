# Prompt_Library

A curated collection of effective prompts and templates for Large Language Models (LLMs).

## 🌟 About

This repository contains a variety of prompts designed to help you get the most out of LLMs such as GPT-4, Claude, Llama, and others. Whether you're looking to improve your coding, creative writing, business communication, or educational content, you'll find useful prompts and templates here.

## 🌟 Featured Prompts

### Educational
- **Study Guide Generator**: Creates detailed study guides with memory techniques, practice questions, and visual learning tools for any subject
- **Lesson Plan Creator**: Generates complete lesson plans with differentiated activities and assessment strategies for teachers
- **Feedback Formulator**: Helps educators create constructive, balanced feedback on student work with specific improvement strategies
- **Study Crew System**: Creates an interactive multi-agent learning experience with specialized coaches to help students with assignments

### Technical
- **Code Explainer for Beginners**: Transforms complex code into beginner-friendly explanations with visual metaphors and real-world examples

## 🔧 How to Use

Each prompt file is stored as a markdown (`.md`) file. To use a prompt:

1. Browse to the relevant category directory
2. Open the prompt file
3. Copy the content from the "Instructions" section
4. Paste into your LLM interface of choice
5. Modify as needed for your specific use case

For prompts with separate example files (identified by `.example.md`), you can review sample outputs to see how the prompt works in practice.

## 📝 Prompt Format

Prompts in this library follow a consistent format:

```
# [Title]

## Purpose
Brief description of what this prompt helps achieve

## Target Models
LLMs this prompt is optimized for (e.g., GPT-4, Claude, etc.)

## Instructions
The actual prompt text (copy this part to use with an LLM)

## Variations
Optional modifications to adapt the prompt for different needs
```

Example files (`.example.md`) contain:

```
# [Title] - Example Output

## Input Parameters
Parameters used to generate this example

## Generated Response
Sample response generated by an LLM using this prompt
```

## 🤝 Contributing

Contributions are welcome! If you have a prompt that you've found effective, please consider sharing it:

1. Fork this repository
2. Add your prompt following the format above (either in a single file or separate prompt/example files)
3. Place it in the appropriate category (or create a new one if needed)
4. Submit a pull request

Please include example outputs and any relevant notes about model behavior.

## 📋 File Organization Guidelines

- Main prompt instructions should be in a `.md` file
- Example outputs should be in a separate `.example.md` file
- Use clear, descriptive filenames
- Organize prompts in appropriate category folders
- Include all sections listed in the Prompt Format
